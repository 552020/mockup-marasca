Per Blender resa fotografica

Un solo file con dentro bottiglia, quote, tappo, etichetta e impostazioni correnti. In Blender (gratuito, blender.org): area Scripting → menu Testo → Apri → scegli il file → Esegui script. La scena compare con vetro, olio, luci e camera pronti per il render Cycles. Il file arriva con estensione .txt: Blender lo legge così com'è.

Sul sito trovi anche lo script Blender da solo, con tutte le opzioni da riga di comando, e le istruzioni.
